# Журнал змін (Changelog) — CoDaS Portal

## [1.0.0] - 2026-11-23
### Додано (Added)
- Повноцінний паспорт міжнародного проєкту Erasmus+ EMJM **CoDaS** (Grant Agreement № 101082451).
- Модуль команди та консорціуму університетів із активними посиланнями на профілі **ORCID**.
- Управління робочими пакетами (`WP1–WP5`) та прогресом виконання результатів (*deliverables*).
- Реєстр наукових публікацій з автозаповненням метаданих за DOI через **Crossref REST API** та фільтрами (`Scopus`, `WoS`, рік, тип).
- Академічний календар заходів, двомовна стрічка новин (`UA | EN`) та відгуки випускників.
- Система розмежування доступу (RBAC) для ролей *Відвідувач*, *Виконавець/Учасник* та *Керівник/Адмін*.
- Конструктор періодичних звітів за обраними датами з експортом у PDF та візуалізацією KPI.
- Конвеєр безперервної інтеграції GitHub Actions (`.github/workflows/ci.yml`) та технічна документація в `docs/`.
