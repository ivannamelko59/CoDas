# Архітектура та технологічний стек порталу CoDaS

## 1. Обґрунтування вибору технологічного стека
Для реалізації вебпорталу звітності наукового проєкту обрано сучасний стек на базі **Next.js (App Router) + TypeScript**:

* **Next.js 15 & React:** забезпечує швидкий рендеринг компонентів, зручну структуру маршрутизації та високі показники продуктивності й SEO (Lighthouse ≥ 90).
* **TypeScript:** гарантує сувору типізацію моделей даних (заявки, публікації, робочі пакети, ролі RBAC), що мінімізує помилки під час розробки та збірки.
* **Tailwind CSS:** використовується для побудови адаптивного інтерфейсу (від 360 px на мобільних екранах до десктопа) та стилів друку PDF.
* **Crossref REST API (`api.crossref.org`):** зовнішній відкритий API для автоматичного отримання бібліографічних метаданих наукових публікацій за ідентифікатором DOI.
* **Vercel & GitHub Actions:** забезпечують безперервну інтеграцію (`npm run lint`, `npm run build`) та автоматичне розгортання кожного коміту в гілку `main`.

## 2. Модель даних та компоненти системи
Система побудована за модульним принципом і охоплює такі сутності:
1. `ProjectPassport` — метадані гранту ЄС (код `101082451`, бюджет, терміни, мета та завдання).
2. `TeamMember & PartnerUniversity` — профілі дослідників з активними посиланнями ORCID та університети консорціуму.
3. `WorkPackage` — робочі пакети `WP1–WP5` із дедлайнами, відповідальними лідерами та прогресом виконання.
4. `Publication` — реєстр публікацій із підтримкою фільтрації за індексацією (`Scopus`, `WoS`), типом і роком видання.
5. `Event & News` — академічний календар заходів та двомовна стрічка новин (`UA / EN`).
6. `Application & DevelopmentIdea` — модуль подачі заявок на мобільність та беклог ідей розвитку.
7. `KPI & ReportBuilder` — аналітика виконання показників і формування зведених звітів у PDF.
