# Визначення готовності (DoR) та визначення виконаного (DoD)

## Definition of Ready (DoR)
Користувацька історія готова до взяття у спринт, якщо:
1. Сформульована за шаблоном: *«Як \<роль\>, я хочу \<дія\>, щоб \<цінність\>»*.
2. Містить чіткі критерії прийняття у форматі *«Дано — Коли — Тоді» (Given — When — Then)*.
3. Оцінена в очках історій (Story Points) і не перевищує 8 очок.
4. Визначено пріоритет за методом MoSCoW та відсутні нерозв'язані блокери.

## Definition of Done (DoD)
Історія вважається виконаною, якщо:
1. Усі критерії прийняття реалізовано та перевірено.
2. Перевірки конвеєра CI у GitHub Actions (`npm run lint` та `npm run build`) пройшли успішно.
3. Зміни автоматично розгорнуто на робочому сайті Vercel і перевірено в браузері.
4. Інтерфейс коректно відображається на мобільних екранах (ширина від 360 px) і відповідає вимогам доступності WCAG 2.2 AA.
5. Усі елементи інтерфейсу перекладені українською та англійською мовами (`UA | EN`).
6. Оновлено документацію проєкту за потреби.
